# Hi, I'm Danish 👋

I'm a computer engineering student at **NYU**. I build computer vision systems for real cameras, unreliable networks, and busy streets—and tools for the things I enjoy, from chess to drawing.

### Selected work

- **[GateWatch](https://github.com/danish-puri/GateWatch)** — Vehicle and pedestrian logging from campus CCTV in Kathmandu, built to run unattended on a CPU-only server.
- **[PrepMate](https://github.com/danish-puri/prepmate)** — Chess opponent scouting: explore openings, results, and patterns in public games. [Try it ↗](https://prepmate-chess.fly.dev)
- **[imaGine](https://github.com/danish-puri/imaGine)** — Draw in the air with your fingertip and a webcam, then save your sketch. [Try it ↗](https://danish-puri.github.io/imaGine/)

### Also built

- **[Einstein Ring](https://github.com/danish-puri/einstein-ring)** — A macOS black hole wallpaper, ray traced in Metal and played as a seamless video loop.
- **[Bird](https://github.com/danish-puri/bird)** — The first version of GateWatch, field-tested at two campuses. [Read the case study ↗](https://osf.io/6s7aw/files/9kch3)
