# Hi, I'm Danish Puri

I study at NYU and I like building computer vision systems that have to work outside the lab, on real cameras, weak networks, and messy traffic.

My main project is a vehicle and pedestrian monitoring system I deployed at campuses in Kathmandu, Nepal. I wrote up the first deployment in the [LibertyTrack case study](https://osf.io/6s7aw/files/9kch3), and the code is in [bird](https://github.com/danish-puri/bird).
